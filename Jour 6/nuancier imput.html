Les différents types d'input HTML
Type Input Cas d'usage
text Saisir un nom ou un texte libre
email Vérifie automatiquement le format email
password Masque les caractères saisis
number Saisir un âge ou une quantité
date Choisir une date de naissance
color Choisir une couleur pour un thème
file Envoyer une photo de profil
checkbox Accepter les conditions d'utilisation
